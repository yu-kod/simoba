# Specification

## Purpose
ゲーム画面下部のHUDパネル（HP/XP/レベル/スキルスロット表示）のレイアウトと描画仕様

## Requirements

### Requirement: HUDパネルの表示位置とレイアウト
HUDパネルは画面下部中央に配置され、カメラスクロールに影響されない固定位置で表示される。半透明ダークパネル背景を持つ。

#### Scenario: HUDがゲーム開始時に表示される
- **WHEN** GameSceneが開始される
- **THEN** 画面下部中央にHUDパネルが表示される
- **THEN** HUDパネルはカメラスクロール・ズームに影響されず固定位置に表示される
- **THEN** HUDパネルはゲームワールドの上（depth 1100）に描画される

#### Scenario: HUDがマッチ終了オーバーレイの下に表示される
- **WHEN** マッチが終了しオーバーレイ（depth 2000）が表示される
- **THEN** HUDパネルはオーバーレイの下に隠れる

### Requirement: スキルスロットの表示
スキルバーはスロット定義の配列に基づいて動的にスロットを描画する。スロットには「アクティブ」「パッシブ」「空」の3種類がある。

#### Scenario: アクティブスキルスロットの表示
- **WHEN** スロット定義に type='active', key='Q' のスロットがある
- **THEN** スロットが正方形で描画される
- **THEN** スロット内にキーラベル「Q」が表示される
- **THEN** スロット内にスキルを示すジオメトリック形状が描画される

#### Scenario: パッシブスキルスロットの表示
- **WHEN** スロット定義に type='passive' のスロットがある
- **THEN** スロットが正方形で描画される
- **THEN** キーラベルは表示されない
- **THEN** パッシブを示すジオメトリック形状が描画される

#### Scenario: 空スロットの表示
- **WHEN** スロット定義に type='empty' のスロットがある
- **THEN** スロットが暗い背景色の正方形で描画される
- **THEN** キーラベルもスキル形状も表示されない

#### Scenario: スロット構成の動的変更
- **WHEN** スロット定義の配列が更新される
- **THEN** HUDスキルバーが新しい構成で再描画される
- **THEN** スロット数の増減に対応する

### Requirement: クールダウン表示
アクティブスキルスロットはクールダウン中に暗転オーバーレイと残り秒数を表示する。

#### Scenario: クールダウン中の表示
- **WHEN** アクティブスキルのクールダウンが残っている（remainingCd > 0）
- **THEN** スロットに半透明の暗転オーバーレイが描画される
- **THEN** 残り秒数が数値でスロット中央に表示される

#### Scenario: クールダウン完了時の表示
- **WHEN** アクティブスキルのクールダウンが0になる
- **THEN** 暗転オーバーレイと秒数表示が消える
- **THEN** スロットが通常表示に戻る

### Requirement: レベルバッジ表示
スキルバー左側に現在のレベルを丸型バッジで表示する。

#### Scenario: レベル表示
- **WHEN** ヒーローのレベルが1〜5のいずれかである
- **THEN** スキルバー左側に丸型バッジが表示される
- **THEN** バッジ内にレベル数値が表示される

#### Scenario: レベル変更時の更新
- **WHEN** ヒーローのレベルが変化する
- **THEN** レベルバッジの数値が即座に更新される

### Requirement: XPプログレスバー表示
スキルバー右側に次のレベルまでのXP進捗を横バーで表示する。

#### Scenario: XP進捗表示
- **WHEN** ヒーローがXPを持っている
- **THEN** スキルバー右側に横プログレスバーが表示される
- **THEN** バーが現在XP / 次レベル必要XPの割合で塗りつぶされる

#### Scenario: 最大レベル到達時
- **WHEN** ヒーローがMAX_LEVEL（5）に到達している
- **THEN** XPバーが100%で表示される（またはMAX表示）

### Requirement: HP数値バー表示
スキルバー下部に現在HP / 最大HPを数値付きバーで表示する。

#### Scenario: HP数値バーの表示
- **WHEN** ヒーローが生存している
- **THEN** スキルバー下部にHPバーが表示される
- **THEN** バーが現在HP / 最大HPの割合で塗りつぶされる
- **THEN** バー上に「現在HP / 最大HP」の数値テキストが表示される

#### Scenario: HPが変化した時の更新
- **WHEN** ヒーローのHPがダメージまたは回復で変化する
- **THEN** HPバーの塗りつぶし幅と数値テキストが即座に更新される

### Requirement: UIスケールユーティリティ
カメラズームに影響されないUI描画のため、ズーム補正ユーティリティを提供する。全フィールド外UIコンポーネントで再利用可能とする。

#### Scenario: ズーム補正によるサイズ計算
- **WHEN** カメラズームが2.0でUIコンポーネントが64pxの意図したサイズを指定する
- **THEN** ユーティリティは32pxの実描画値を返す
- **THEN** カメラズーム適用後に画面上で64pxに見える

#### Scenario: ズーム値変更時の自動対応
- **WHEN** カメラズーム値が変更される
- **THEN** ユーティリティの引数が変わるだけで全コンポーネントが自動的に正しいサイズで描画される

### Requirement: デバッグ用初期スキル構成
スキルシステム未実装の間、3種類のスロット状態（アクティブ/パッシブ/空）を確認できるデバッグ用の仮スロット定義を提供する。

#### Scenario: デバッグ用スロット構成の表示
- **WHEN** タレントツリーが未実装の状態でゲームが起動される
- **THEN** アクティブ1スロット（Q）＋パッシブ1スロット＋空1スロットが表示される
- **THEN** スキルキーを押しても効果は発生しない（表示のみ）
