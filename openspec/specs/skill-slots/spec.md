# Specification

## Purpose

スキルスロットシステム — ヒーローが獲得したスキルを Q/E/R キーに割り当て、試合中に使用するための仕組み。

## Requirements

### Requirement: スキルスロット構造
`HeroSchema` は `skillSlotQ`、`skillSlotE`、`skillSlotR` フィールド（各 `string` 型）を持たなければならない（SHALL）。空文字はスロット未設定を意味しなければならない（SHALL）。各フィールドは Colyseus `@type` で全クライアントに同期されなければならない（SHALL）。

#### Scenario: 初期状態
- **WHEN** ヒーローが生成される
- **THEN** `skillSlotQ`、`skillSlotE`、`skillSlotR` は全て空文字である

### Requirement: 空スロットへのスキル装着
プレイヤーは所持スキルを空のスキルスロットにドラッグ&ドロップで装着できなければならない（SHALL）。この操作はマップ上のどこでも実行可能でなければならない（SHALL）。クライアントは `assignSkillSlot` メッセージ（`skillId: string, slot: 'Q'|'E'|'R'`）をサーバーに送信しなければならない（SHALL）。サーバーは該当スキルが `ownedSkills` に存在し、対象スロットが空であることを検証しなければならない（SHALL）。

#### Scenario: 空スロットに新スキルを装着
- **WHEN** プレイヤーが所持スキル `blade-charge` を空の Q スロットにドロップする
- **THEN** `skillSlotQ` が `blade-charge` に設定される

#### Scenario: 所持していないスキルの装着拒否
- **WHEN** プレイヤーが `ownedSkills` に存在しないスキルIDで `assignSkillSlot` を送信する
- **THEN** サーバーはメッセージを無視し、状態は変化しない

### Requirement: スキルの入れ替え（拠点限定）
プレイヤーはスキルスロット間のスキル入れ替え（swap）を拠点エリア内でのみ実行できなければならない（SHALL）。クライアントは `swapSkillSlots` メッセージ（`slotA: 'Q'|'E'|'R', slotB: 'Q'|'E'|'R'`）をサーバーに送信しなければならない（SHALL）。サーバーはプレイヤーの位置が拠点エリア内であることを検証しなければならない（SHALL）。拠点外での要求は無視されなければならない（SHALL）。

#### Scenario: 拠点内でスロット間入れ替え
- **WHEN** プレイヤーが拠点エリア内にいて、Q スロットのスキルを E スロットにドラッグする
- **THEN** Q と E のスキルが入れ替わる

#### Scenario: 拠点外での入れ替え拒否
- **WHEN** プレイヤーが拠点エリア外にいてスロット間の入れ替えを要求する
- **THEN** サーバーはメッセージを無視し、状態は変化しない

### Requirement: スキルの解除（拠点限定）
プレイヤーはスロットからスキルを所持スキル一覧にドラッグ&ドロップで解除（unequip）できなければならない（SHALL）。この操作は拠点エリア内でのみ実行可能でなければならない（SHALL）。クライアントは `unequipSkillSlot` メッセージ（`slot: 'Q'|'E'|'R'`）をサーバーに送信しなければならない（SHALL）。

#### Scenario: 拠点内でスキル解除
- **WHEN** プレイヤーが拠点エリア内にいて、Q スロットのスキルを所持スキル一覧にドロップする
- **THEN** `skillSlotQ` が空文字に設定される

#### Scenario: 拠点外での解除拒否
- **WHEN** プレイヤーが拠点エリア外にいてスキル解除を要求する
- **THEN** サーバーはメッセージを無視し、状態は変化しない

### Requirement: スキルスロット UI（タレントツリー画面内）
タレントツリー UI 内に所持スキル一覧と Q/E/R スキルスロットが表示されなければならない（SHALL）。スキルアイコンはドラッグ&ドロップで操作可能でなければならない（SHALL）。拠点外にいる場合、入れ替え・解除操作はグレーアウトまたはツールチップで制限理由を表示しなければならない（SHALL）。

#### Scenario: タレントツリー画面でのスキル一覧表示
- **WHEN** プレイヤーがタレントツリー UI を開く
- **THEN** 所持スキル一覧と Q/E/R スロットが表示される

#### Scenario: 拠点外での制限表示
- **WHEN** プレイヤーが拠点外でタレントツリーを開き、スロット入れ替えを試みる
- **THEN** 操作が無効化され、「拠点に戻ってスキルを入れ替えよう」等のフィードバックが表示される
