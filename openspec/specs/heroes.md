# ヒーロー

## スキル構成（全ヒーロー共通）

各ヒーローは 3 つのスキルスロット（Q / E / R）を持つ。初期状態ではすべて空で、タレントツリーでスキルを習得し、スロットに割り当てて使用する。

- **通常攻撃** — 右クリック（スロット不要、常時使用可能）
- **スキルスロット Q / E / R** — タレントで習得したスキルを割り当て

パッシブなし。深さよりシンプルさ。

## BLADE — ファイター（近接）

| プロパティ | 値 |
|-----------|-----|
| ロール | フロントライン |
| 射程 | 近距離（60px） |
| プレイスタイル | 突入して AoE ダメージ |
| 基本ステータス | HP 650 / 速度 170 / 攻撃力 60 / 攻撃速度 0.8 |

**タレントで習得可能なスキル:**
- **Charge** — カーソル方向に 300px ダッシュ + 80 ダメージ（CD 8秒）
- **Dodge Roll** — 移動方向に 150px 無敵ダッシュ（CD 8秒）
- **Block** — 3秒間、被ダメージを固定値 30 吸収するセルフバフ（CD 10秒）
- **Fortify** — 4秒間、被ダメージ 30% 軽減するセルフバフ（CD 14秒）
- **Fury** — 5秒間、攻撃力 +25 / 攻撃速度 +0.5 のセルフバフ（CD 18秒）
- **Execute** — 敵単体に 100 ダメージ、HP 30% 以下なら 250 ダメージ（CD 20秒）
- **Whirlwind** — 3秒間追従する回転ゾーン、0.5秒ごとに 30 ダメージ（CD 12秒、自己スロー -40）

## BOLT — レンジャー（遠距離）

| プロパティ | 値 |
|-----------|-----|
| ロール | バックライン |
| 射程 | 長距離（300px） |
| プレイスタイル | カイト、ゾーンコントロール |
| 基本ステータス | HP 400 / 速度 220 / 攻撃力 45 / 攻撃速度 1.0 |

**タレントで習得可能なスキル:**
- **Dash** — 180px 高速回避ダッシュ（CD 6秒）
- **Pierce Shot** — 貫通弾丸、60 ダメージ、3体貫通（CD 5秒）
- **Trap** — 地面にトラップ設置、踏んだ敵に 70 ダメージ + 2秒スロー（CD 10秒）
- **Barrage** — 扇状に 5 発の弾丸を発射、各 25 ダメージ（CD 10秒）
- **Ricochet** — 敵間を 3 回跳ね返る弾丸、50 ダメージ（CD 8秒）
- **Snipe** — 5秒間、攻撃力 +20 / 攻撃速度 +0.4 / 移動速度 -60（CD 16秒）
- **Turret** — タレットを設置、10秒間自動攻撃（CD 20秒）

## AURA — サポート

| プロパティ | 値 |
|-----------|-----|
| ロール | バックライン / フレックス |
| 射程 | 中距離（200px） |
| プレイスタイル | 味方を保護、持続戦 |
| 基本ステータス | HP 500 / 速度 190 / 攻撃力 30 / 攻撃速度 0.7 |

**タレントで習得可能なスキル:**
- **Heal** — 味方の HP を 120 回復（CD 10秒）
- **Haste** — 味方の移動速度 +80 を 3秒間付与（CD 12秒）
- **Weaken** — 敵の攻撃力 -15 を 4秒間付与（CD 14秒）
- **Barrier** — 指定地点にゾーン設置、範囲内の味方に 30% ダメージ軽減（CD 14秒）
- **Slow Field** — 指定地点にゾーン設置、範囲内の敵に移動速度 -60（CD 14秒）
- **Nova** — AoE 攻撃、敵に 80 ダメージ + 味方に 60 回復（CD 16秒）
- **Sanctuary** — キャスター追従ゾーン、味方に定期回復 + 25% ダメージ軽減（CD 20秒）

## タレントシステム

- **最大レベル:** 30。レベルアップごとにタレントポイントを1付与。
- **タレントツリー:** 各ヒーローは扇形の固有ツリーを持つ（45〜55ノード、根が下、枝が上に展開）。
- **可変コスト:** ノードコストは1、2、または3タレントポイント。コスト1 = ステータス微調整、コスト2 = スキルアップグレード、コスト3 = ゲームチェンジャー。
- **ビルド多様性:** 30ポイントで全ノードの30〜40% のみ取得可能。毎試合異なるビルドを保証。
- **XP カーブ:** セグメント式（序盤高速、中盤線形、終盤急勾配）。通常の試合ではLv15〜25に到達。
- **Lv3:** アルティメット解放。
- **Lv5:** アルティメット強化。
